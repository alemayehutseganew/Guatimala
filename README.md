# Ethio Bingo

Telegram Mini App project.

## Backend

```bash
cd backend
npm install
npm start
```

Create a `.env` file in the `backend` directory with your configuration (e.g. `PORT`, database credentials, `BOT_TOKEN`, `JWT_SECRET`).

## Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend dev server runs on Vite's default port (usually 5173).
